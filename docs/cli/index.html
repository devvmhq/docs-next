CLI reference

CLI reference

Every devvm command, with its arguments and flags. devvm <command> --help prints the same.

  • devvm: Open a shell in this folder’s VM, creating it first
  • devvm adopt: Give this folder the VM made for an earlier folder or path
  • devvm agent: Fill devvm’s store of the agents’ settings and logins that every VM gets
  • devvm agent import: Copy the agents’ settings and logins from this machine into devvm’s store
  • devvm agent login: Log an agent in, in this folder’s VM, and save the login in devvm’s store
  • devvm agent save: Copy the agents’ settings from this folder’s VM into devvm’s store
  • devvm build: Build an image and the images under it, unless they’re built
  • devvm clone: Show or change whether this folder’s VM has its own clone of the repo
  • devvm clone add: Copy one more repo into this folder’s –clone VM
  • devvm clone fetch: Fetch the work of this folder’s –clone VM into each of its repos
  • devvm code: Open this folder’s VM in VS Code over Remote-SSH
  • devvm completion: Print the shell completion script for bash, zsh or fish
  • devvm cursor: Open this folder’s VM in Cursor over Remote-SSH
  • devvm desktop: Open this folder’s VM’s desktop in a VNC viewer
  • devvm doctor: Check what devvm needs on this machine
  • devvm gc: Delete stale images, unused tools, old files and the Nix cache over its cap
  • devvm git-protect: Show or change .git protection for this folder’s VM
  • devvm group: Show the group this folder’s VM is in
  • devvm group join: Put this folder’s VM in a group of VMs
  • devvm group leave: Take this folder’s VM out of its group
  • devvm history: List the saved exports of agents’ history
  • devvm history export: Save this folder’s VM’s agent history to a .tar.gz
  • devvm history import: Put an export of agent history into this folder’s VM
  • devvm host: Get this folder’s VM ready for ssh and editors, and show its host name
  • devvm images: List the images and the shared tools
  • devvm images rm: Delete images, by name or by key
  • devvm layer: Make image layers of your own, or change this folder’s VM’s layers
  • devvm layer add: Make this folder’s VM again with more layers, then open a shell in it
  • devvm layer new: Start a layer of your own
  • devvm layer rm: Make this folder’s VM again without some of its layers, then open a shell in it
  • devvm limactl: Run Lima’s limactl for debugging, which starts VMs unconfined, whatever their tier
  • devvm link: List this folder’s VM’s links to your other VMs
  • devvm link add: Link this folder’s VM to a port of another VM
  • devvm link publish: Show or add the ports this folder’s VM offers to links
  • devvm link rm: Remove one of this folder’s VM’s links
  • devvm link unpublish: Stop offering ports of this folder’s VM to links
  • devvm ls: List the project VMs
  • devvm mount-cache: Show or change how this folder’s VM caches its project folder
  • devvm network: Show or change the network tier of this folder’s VM
  • devvm network allow: Allow hosts for this folder’s VM
  • devvm network deny: Deny hosts for this folder’s VM
  • devvm network lock: Lock this folder’s VM to the hosts it learned, on the allowlist tier
  • devvm network log: Show what this folder’s VM connected to and what its proxy blocked
  • devvm network rm: Remove rules from this folder’s VM
  • devvm network transparent: Show or change transparent mode for this folder’s VM
  • devvm paste: Send the clipboard’s image, PDF or copied file to this folder’s VM
  • devvm paste rm: Delete the files devvm paste left in this folder’s VM
  • devvm ports: Show or change which ports this folder’s VM forwards
  • devvm ports add: Forward more ports from this folder’s VM
  • devvm ports rm: Stop forwarding some ports from this folder’s VM
  • devvm rebuild: Build an image again, and delete the old one
  • devvm restart: Restart this folder’s VM and open a shell in it
  • devvm retention: Show or change what devvm deletes on its own
  • devvm rm: Delete this folder’s VM, or a VM whose folder is gone
  • devvm secret: List the secrets kept on this machine, for VMs to use
  • devvm secret rm: Delete a saved secret
  • devvm secret set: Save a secret on this machine
  • devvm secret unuse: Stop this folder’s VM using a secret
  • devvm secret use: Let this folder’s VM use a secret
  • devvm setup: Choose base’s features, and new VMs’ size, network tier, coding agents and layers
  • devvm size: Show or change this folder’s VM’s size
  • devvm space: Show what devvm keeps on this machine and the space it takes
  • devvm ssh-agent: Show or change SSH agent forwarding for this folder’s VM
  • devvm ssh-agent add: Load a key into devvm’s own SSH agent
  • devvm ssh-agent rm: Remove a key from devvm’s own SSH agent
  • devvm stop: Stop this folder’s VM
  • devvm tools: Show or choose this folder’s VM’s shared tools
  • devvm tools add: Add shared tools to this folder’s VM, then open a shell in it
  • devvm tools rm: Take shared tools out of this folder’s VM, then open a shell in it
  • devvm tools update: Move this folder’s VM to the newest shared tools, then open a shell in it
  • devvm update: Bring this folder’s VM up to date, then open a shell in it
  • devvm upgrade: Install devvm’s newest release
