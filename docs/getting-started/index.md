# Getting started

These pages take you from installing devvm to working in your first VM.

- [Installing](install.md): what devvm needs on your machine, how to install it with Homebrew or the install script, and how to check it with `devvm doctor`.
- [Your first VM](first-vm.md): making a VM for a project folder, logging Claude Code in, starting the agent, and coming back to the VM later.
- [Everyday commands](commands.md): devvm's commands in the groups `devvm --help` shows, with the options for a new VM.
