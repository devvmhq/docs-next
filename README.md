# docs-next

The built docs for the next, unreleased devvm, served at [next.devvm.dev](https://next.devvm.dev). The docs for the current release are at [devvm.dev](https://devvm.dev).

Everything here is generated: [devvm](https://github.com/devvmhq/devvm)'s Docs workflow builds the site from `main` and pushes it here when the docs change, and Cloudflare Pages publishes it. Don't edit it by hand. Change the docs in [devvm's `docs/`](https://github.com/devvmhq/devvm/tree/main/docs) instead.
